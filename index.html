Twitter Analytics Dashboard

Real-Time Twitter Analytics Dashboard using Power BI

Project Overview

This project focuses on analyzing Twitter data using Microsoft Power BI. The dashboard provides insights into tweet interactions, engagement rates, media interactions, monthly trends, and top-performing tweets.

Tools & Technologies

Power BI DAX Data Visualization Data Analysis

Project Tasks

Task 1 – Tweet Interaction Breakdown

Created a clustered bar chart showing URL clicks, user profile clicks, and hashtag clicks grouped by tweet category.

Task 2 – Engagement Rate Comparison

Compared the average engagement rate of tweets with app opens and tweets without app opens using the required filtering conditions.

Task 3 – Media Interaction by Day of Week

Created a dual-axis visualization comparing media views and media engagements across different days of the week.

Task 4 – Replies, Retweets and Likes

Developed a bar chart comparing the total replies, retweets, and likes for tweets posted between June and August 2020.

Task 5 – Monthly Engagement Rate Trend

Created a line chart comparing average engagement rates for tweets with media and tweets without media across different months.

Task 6 – Top 10 Tweets by Engagement

Created a visualization identifying the top 10 tweets based on total engagement calculated from retweets and likes.

Key Learning Outcomes

  • Created different Power BI visualizations.
  • Used DAX measures for engagement calculations.
  • Applied multiple data filters and conditions.
  • Configured time-based visualization visibility.
  • Worked with aggregation and sorting.
  • Analyzed Twitter engagement patterns and trends.
